# Houser Engineering project photos

Reviewed static release of the Houser project photo app, hosted using the existing test-pit app's GitHub Pages method.

App: https://houserengineering.github.io/project-photos/

Source: `apps/project-photos` in Houser Engineering, branch `codex/project-photos`.
Runtime source commit: `92632b13f`.

This repository contains the public app shell only. The private project catalog is loaded after office sign-in and is not deployed here.

Initial setup: open Account, sign in with the shared survey Google account, refresh the project list, select and confirm the job, and allow camera access. Set up each device online before fieldwork. Pending stamped photos stay in the app's private browser storage until the image and companion record are confirmed by Dropbox. Reopen the app with a connection to finish delivery.

Physical phone camera, orientation, stamp readability, and storage lifecycle acceptance remain for device review. Desktop automated checks do not complete that acceptance.
